# Reel stage completion

Reels and legacy Video jobs now accept a fresh post-submit upload-complete transition, or an observed copyright-scan transition that has cleared. Before confirming, the publisher obtains another notification snapshot and UI hierarchy, checks for active uploads, pending publication stages, composer screens, unsafe/foreign UI and actual Facebook errors. Errors take precedence. Completion does not require a Home layout match, success banner, profile lookup or the older 30-second quiet window.

A Home refresh that cannot be verified no longer immediately sets Unknown. Monitoring continues under the existing overall timeout. The existing stable-cycle and direct-success routes remain available. Story confirmation is unchanged. Existing history outcomes are not rewritten and no live post was submitted during this change.
