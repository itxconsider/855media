# Queue preparation duplicate exclusion

November 8, 2026. The reported LD6 Nick Parlet queue displayed a Scheduled row followed by a skipped duplicate row. Runtime fingerprinting blocked the second submission; preparation only reserved paths and its device/binding match could also miss an alias of a known target.

Preparation now excludes matching paths and duplicate SHA256 content before choosing the requested number of files. Renamed copies therefore cannot consume separate slots. Existing rows with the same known target ID, Page/Profile type and media type reserve sources consistently with the runtime target-scoped guard, even across device/binding aliases. The unique-across-targets option continues reserving all targets. Equal file sizes only identify comparison candidates; equal-size files with different content remain eligible. Hashing occurs off the UI thread and only for sizes that could collide. Errors stop preparation rather than accepting unverified content. Runtime fingerprint/history reservation remains the final submission guard.
