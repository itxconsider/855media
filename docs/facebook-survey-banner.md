# Facebook Feed survey banner

Shared navigation prompt handling now recognizes the personalized “we'd like to improve Facebook for everyone” banner, exact short-survey question and Start Survey action within a bounded banner card. It closes only a unique usable small control at the card's upper-right corner. An unlabeled control is allowed because the LD-56 capture exposed no accessibility close label. It never taps Start Survey.

The handler rejects editable/authentication/foreign layouts, hidden/disabled controls, unrelated headings/questions and controls outside the banner close area. One acknowledged tap is followed by up to five 400 ms observations. A persistent banner or unacknowledged tap stops navigation; no repeated tap is attempted. Existing streak/email handling remains wired into the same flow, so consumers using shared navigation prompts benefit without a new target-selection policy.
