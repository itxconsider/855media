The prior successful live test explicitly enabled API lookup and did not exercise this native link/settings navigation stack. API lookup returns before setting the obligation and does not gain an extra Feed transition.

A failed Feed return aborts rather than falling through to the leftover profile/settings dropdown. No process baseline reset, restart, additional Graph request, guessed tap or new saved-identity fallback is introduced. Own-link cleanup, final actor name/type/list verification and persistence guards remain unchanged. LD9/LD14 Recents are untouched.
