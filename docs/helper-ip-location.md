# 885Helper IP and approximate location

Implemented 2026-11-03. 885Helper1.0.1 now exposes a protected `/network` query and a launcher-screen Check IP and location action. It makes one fixed HTTPS IPWhois request from Android, with normal TLS validation, redirects disabled, 16KB response limit, bounded worker queue and a 6.5-second caller timeout. Only public IP/city/region/country are returned with protocol, timestamp and duration. Requests are fresh, without a persistent network cache. No GPS access, host IP substitution, arbitrary URLs or open server is introduced. Per-app VPNs can give the helper a different route than Facebook; the desktop retains that disclosure.

Desktop network rows prefer the helper through installation-owned direct ADB, validate protocol/freshness/public IP and reuse the existing location parser. Older helpers upgrade from the bundled signed APK. Missing or unsupported helpers fall back to the existing guest curl route.
