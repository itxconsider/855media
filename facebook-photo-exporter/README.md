# Facebook Photo Exporter (Chrome Extension)

## Load extension
1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select folder: `C:\Users\lolie\source\repos\MediaTag\facebook-photo-exporter`.

## Use
1. Open a Facebook profile/page photos view.
2. Click the extension icon.
3. Click **Start**.
4. Let it scroll/load for a while.
5. Click **Stop**.
6. Click **Export TXT** or **Export JSON**.

## Notes
- It collects direct image URLs (`scontent...`, `fbcdn.net`, `lookaside.fbsbx.com`).
- Paste exported URLs (one per line) into MediaTag to batch download.
