# Auto-Accept File Changes & Autonomous Execution

- **Auto-Accept Edits**: All proposed code changes, refactors, and file updates should be written directly to the target files without asking for confirmation beforehand.
- **Autonomous Build & Verification**: After applying file changes, automatically run builds and validation checks to verify correctness without waiting for manual user prompts.
- **Concise Reporting**: Present completed changes and verification results cleanly with file links.
