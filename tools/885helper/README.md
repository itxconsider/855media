# 885Helper APK

Build source and instructions: ../../android/885Helper/README.md.

885Helper.apk 1.0.0 is the Android companion for 855Media. Install using the assigned LD's ADB connection. Status uses a shell/root-protected content provider, not an open network server. New desktop packages attempt installation after boot and log helper885.* results. No changes to Android device identifiers are made.
